StudyLens

Projeto web para simulação de melhoria de fotos com IA.

Tecnologias:

-React
-JavaScript
-Vite
-HTML e CSS
-LocalStorage

Como instalar:

É necessário ter o Node.js instalado.
Na pasta do projeto, execute:
npm install

Como executar:

Execute
npm run dev
Depois, abra o endereço mostrado no terminal, do servido local
Login:
O projeto não possui sistema de login. Não é necessário usuário ou senha.

Inteligência Artificial:

A IA foi utilizada como apoio no desenvolvimento da estética do site, ajudando na escolha de cores e de elementos visuais e em algumas funcionalidades como selecionar e salvar imagens.
